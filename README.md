# Morin Electric LLC — Marketing Site

Marketing website for Morin Electric LLC, a family-owned residential and commercial electrical contractor serving the Pioneer Valley and Western Massachusetts (Sunderland / South Deerfield, MA). Built with a services grid, About section, free-quote request form, and customer review carousel. Static HTML, deployed via GitHub Pages.

Live site: https://digisyn-co.github.io/morin-electric-site/
